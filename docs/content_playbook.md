# リール制作ルール

`ai_instagram_content_refill` ルーチンと手動制作の共通ルール。根拠は `research/competitor_analysis_2026-10.md` と `reports/` の実測値。

## 実測から決めたこと(2026-11-01時点)

- 静止画のリーチは1〜2、リールは25〜107。投稿はリールのみ。
- 無音スライドの平均視聴時間は0.9〜2.3秒で、2枚目の前に離脱していた。最初の1秒で内容が分かり、動きと音があることを必須にする。
- 「あなたの1位は?」のような開いた質問ではコメントが0件だった。最後は二択にし、答え方はキャプションの5番(絵文字1つでコメント)に合わせる。

## テーマ

- 優先する型:判定(アリ/ナシ)、クイズ(答えを後に出す)、ツール×ツール、設定1つ、撮るだけ・話すだけ。
- 長いプロンプトのテンプレ、一般論の比較表は作らない。プロンプトは1行以内。
- 型が同じ投稿を3本続けない。`queue/posts.json` の過去テーマと重複させない。
- 最新の `reports/analysis_*.md` を読み、リーチ・平均視聴時間が高い型を増やす。

## 台本の書き方

- 全体12〜18秒、6シーン前後。1シーンに1メッセージ。
- フックは2行〜3行で、問いかけか損失を入れる。`sub` で最後まで見る理由を作る。
- AIの出力が結果になるテーマ(chatシーンがある回)は、フックに `result` を付けて完成形を最初の1フレームから見せる。文字だけの冒頭は11月初めの時点でも平均視聴1.1〜1.6秒だった。`result` は1〜4行、フックの `text` は2行にする。
- 判定の回は、判定する項目の一覧を `result` で最初に見せる。設定の回は、設定した後どうなるかを `result` で見せる。
- クイズの回は、フックに `choices`(AとBの2つ)を付けて問題と選択肢を1フレーム目でそろえる。直後に同じ二択の `ab` シーンは入れない。
- 文字だけのフックは、上のどれにも当てはまらない時だけ使う。
- 画面の文字は短く。1行14文字以内を目安にする。
- 最後は必ず `ab` シーンにする。

台本は `content/<id>.json` に保存する。`[...]` は赤文字、`\n` は改行、`sec` は表示秒数(0.5秒単位に丸められる)。

| type | 必須 | 任意 | 用途 |
|---|---|---|---|
| hook | text | sub, result(配列), result_title, choices([A, B]) | 1シーン目。resultは完成形の白いカード、choicesはクイズの選択肢 |
| text | text | sub | 説明 |
| prompt | text, prompt | | 打つ一言や設定項目を白い箱で見せる |
| verdict | label, stamp, good | sub | 判定。goodがtrueで緑、falseで赤 |
| ab | text, a, b | sub | 二択 |
| chat | user, ai(配列) | | チャット画面のイメージ |

```bash
python reel_builder.py content/<id>.json
```

## 事実確認

- 操作手順、機能名、料金、無料か有料かは、制作のたびにWeb検索で公式情報を確認する。確認できないものは使わない。
- チャットの回答例は説明用のイメージで、実際のサービス画面に見せない。ロゴや実在サービスの画面を模倣しない。
- 根拠のない数字や断定(◯時間削減、◯倍、時間がゼロになる、など)、実績の創作、「絶対」「誰でも稼げる」などの断定は書かない。
- 実名の代表者のアカウントなので、競合やツールをけなさない。判定には必ず理由を添える。
- 情報漏えい、要確認事項など、必要な注意点はキャプションに書く。

## キャプション

1. 【問いかけ】
2. 2〜3行で結論
3. 【やり方】①〜③(手順があるテーマのみ)
4. ⚠️注意点
5. 二択のお願い:`あなたはどっちですか?コメントに絵文字1つでOK→ Aなら👍、Bなら🔥` (2026-11-09時点でコメント0件が17本続いたため、文字を打つ手間を減らす形に変更。Instagramのフィード投稿には絵文字リアクション機能がないので、「リアクションして」とは書かず必ず「コメントに」と書く)。画面の最後の `ab` シーンの `sub` も「コメントに👍か🔥だけでOK」にそろえる
6. 反応のお願い:`役に立ったら❤️を、あとで試すなら"保存"をお願いします。`
7. 署名ブロックとハッシュタグ5個(`queue/posts.json` の直近の投稿に合わせる)

## キューへの追加

`queue/posts.json` の末尾に追加する。

```json
{
  "id": "week4-verdict",
  "date": "2026-11-01",
  "video": "images/week4_reel_verdict.mp4",
  "caption": "...",
  "posted": false
}
```

追加後は `python queue_status.py` で検証する。
